Welcome to Immo MLOps.
Machine learning project for real estate price prediction in France.

The goal of this project is to build a simple MLOps pipeline that collects real estate data, preprocesses it, trains a model, evaluates its performance, and serves predictions through an API.

How it works

1. Input

The user provides information about a property: location, surface, number of rooms and other characteristics.

2. Machine Learning model

The data is processed using the same preprocessing pipeline used during training, then sent to the trained regression model.

3. Prediction

The model returns an estimated real estate price based on the characteristics provided by the user.
